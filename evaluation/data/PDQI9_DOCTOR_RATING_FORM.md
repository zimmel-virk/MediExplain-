# MediExplain+ Clinical Summary Evaluation

## Instructions

For each consultation:

1. Read the source consultation transcript.
2. Read the AI-generated clinician-facing clinical note.
3. Score each PDQI-9 category from 1 to 5.
4. Compare the generated note directly with the transcript.
5. Record any factual errors.
6. Do not judge whether you personally agree with the doctor's treatment.
   Judge whether MediExplain+ accurately represented what was said.

## PDQI-9 scoring

Use:

1 = Very poor
2 = Poor
3 = Acceptable
4 = Good
5 = Excellent

### 1. Up-to-Date

Does the note represent the information from this consultation without using stale or irrelevant information?
